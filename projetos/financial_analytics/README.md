# Financial Analytics

Projeto de análise financeira focado em:

## Tópicos Principais

- **Indicadores de Desempenho** — Entender os principais KPIs financeiros
- **Lucratividade de Produtos e Clientes** — Identificar e analisar a rentabilidade
- **DRE por Comportamento e Margem de Contribuição** — Análise estruturada de custos
- **Breakeven Analysis** — Ponto de equilíbrio e alavancagem operacional
- **Orçamento e Projeção** — Projeção de demonstrações contábeis
- **Orçamento Base Zero (OBZ)** — Conceitos e diferenças vs. processo tradicional
- **Real vs. Orçado** — Análise de variações orçamentárias
- **Gestão com Base em Valor** — EVA e drivers de valor da empresa

## Integração MCP

Este projeto utiliza um servidor MCP SQL Server para consultar dados do sistema Protheus via linguagem natural.

**Configuração:** `~/.claude/.mcp.json` (credenciais não commitadas)

**Status de Conexão:** Aguardando liberação de firewall para porta 37000
